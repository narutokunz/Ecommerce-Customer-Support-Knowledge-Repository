
# Return Policy

## Purpose

This document contains the return-related knowledge for the e-commerce customer-support system.

## Return Eligibility

- Customers can request a return within 7 days of delivery.
- The product should be eligible according to the applicable business return policy.
- The product should be returned in acceptable condition.

## Return Process

1. Log in to the customer account.
2. Open the order details.
3. Select the return option.
4. Choose the reason for return.
5. Submit the return request.
6. Follow the instructions provided by customer support.

## Damaged Product

If a product is received damaged, the customer should provide photographs of the product and contact customer support for further assistance.

## Knowledge Rule

IF a customer wants to return an eligible product within the return period,

THEN guide the customer through the return-request process.
